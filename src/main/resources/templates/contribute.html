contribute

Submit projects in-app for review, or help maintain the seed catalog via GitHub.

  1. 1. Submit in-app

    Sign in and use the submit form. Entries are published after moderator review.

    open submit form

  2. 2. Suggest via Issue

    Open a structured issue if you prefer GitHub for the initial proposal.

    open suggest-project issue

  3. 3. Seed catalog Pull Request

    Maintainers can still PR JSON under src/main/resources/catalog/projects/{id}.json for seed data.

    open compare / PR

  4. 4. Rules

    • Metadata and outbound links only — never ROMs, ISOs, or game assets.
    • Ids are lowercase kebab-case and unique.
    • Prefer official project repositories and homepages.

    github.com/caiosouzabdev/portfinder
