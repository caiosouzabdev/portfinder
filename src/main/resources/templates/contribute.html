contribute

The catalog is git-backed. Suggest projects with Issues; add or edit entries with Pull Requests.

  1. 1. Suggest via Issue

    Open a structured issue if you found a decomp/recomp port that should be listed.

    open suggest-project issue

  2. 2. Add via Pull Request

    Create src/main/resources/catalog/projects/{id}.json matching the schema in CONTRIBUTING.md, then open a PR.

    open compare / PR

  3. 3. Rules

    • Metadata and outbound links only — never ROMs, ISOs, or game assets.
    • Ids are lowercase kebab-case and unique.
    • Prefer official project repositories and homepages.

    github.com/caiosouzabdev/portfinder
